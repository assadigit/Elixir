# V0.6.1 — the V0.5.21 backlog shipped: the thin gap-fill prompt tightening · the glossary pair-form dedup · the Searles see-also bound

The three code-fixable backlog items from the pipeline-quality audits — each filed by a real audit finding on a real book run, each fixed content-agnostically.

## The three fixes

- **1. Thin gap-fill prompt tightening** (`gap_fill_batch.py`): the roster gap-fill prompts now demand a "SPECIFIC contribution" per author, with the V0.5.19 generic-verb registry banned from the inline prompts. The banned set is exactly the detector's known-thin vocabulary — the prompt can no longer elicit what the flag then catches.
- **2. Glossary pair-form dedup** (`glossary_parser.py`): "Smith and Jones" vs "Jones and Smith" (also `&`, different years) collapsed to one author via an unordered two-surname key — all 3 parse tiers + the persist/cross-reference downstream. Non-commuted, 3-name, and degenerate forms untouched.
- **3. The see-also bound** — the subtle one: a see-also author was credited with the CLAIM-HOLDER's words that sit in the same source sentence. The bound therefore grounds on the GLOSSARY CONTEXT ONLY (source-sentence grounding would pass exactly the inflation the bound exists to catch). Floor 0.55 (the house containment precedent). A bound-rejected author finishes honestly missing — the documented precision-over-coverage trade.
