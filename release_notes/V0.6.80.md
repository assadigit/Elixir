## The scrollbar catch

The reference viewport (1536×1024) shows the entire dashboard with **no
scrollbar**; ours scrolled ~200 px. Two stacked causes, both found by
measuring the live layout rather than reading code:

1. **The hero's layout sizeHint was 565 px** against its 340 px panel —
   the wordWrap labels' preferred heights leak into the page's minimum.
   The hero's height is now FIXED to the reference proportion (29% of
   the content width, clamped 240–340).
2. **A grid reflow from 2 to 3 columns left QGridLayout's retired rows
   carrying their stale 120 px minimums** (QGridLayout cannot delete
   rows) — reflows now reset every row's minimum. This alone was ~240 px
   of phantom page height.

The page's minimum is now **817 px against the 854 px viewport** —
everything fits, exactly like the reference.
