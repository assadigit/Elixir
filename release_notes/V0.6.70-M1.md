# V0.6.70-M1 — the redesign begins: Elixir's entire visual language moves to the approved forest-green / sage / warm-ivory direction, Inter is bundled, and every colour in the app now flows from one place

> **This is a PRE-RELEASE preview tag** of the UI/UX redesign programme's
> first milestone (M1 — the visual foundation). It ships the source tree
> only: there is **no Windows installer** at this tag, `VERSION` is still
> `0.6.69`, and the dashboard redesign itself (sidebar, hero, Quick Tools
> grid) arrives in **V0.6.70 proper** at the M2 milestone. The shipping
> installer remains the **V0.6.69-windows** Latest release. Published with
> the user's explicit authorization on 2026-11-01 (AGENTS.md Rule 6).

## The programme this ships

The approved UI/UX redesign package replaces the old terracotta-amber
"Editorial Quiet" language with the muted forest-green / sage /
warm-ivory / charcoal direction — "Knowledge, distilled into clarity."
The work is staged in milestones: **M0** reconnaissance (the repository
map and the eight locked user decisions, `docs/M0_RECON_REPORT.md`),
**M1** the visual foundation (this tag), **M2** the dashboard (fixed
sidebar + Full Conversion hero + Quick Tools → V0.6.70), **M3** polish,
**M4** documentation & release handoff.

## What you get (in plain words)

Run Elixir from source at this tag and the app already *feels* different
before a single layout moves:

- **New colours everywhere, in both themes.** Light mode is warm ivory
  paper with forest-green accents; dark mode is soft charcoal-olive with
  sage. The old terracotta-amber accent is fully retired — including all
  the places that used to carry their own hand-picked colours: the
  startup splash, the PDF drop overlay, the tab flash, every status dot
  and badge and banner in the dependencies dashboard, the TTS
  connectivity dots, the GPU status banners, the token-cost captions.
- **Inter is now bundled** (4 weights from the official release, SIL OFL
  1.1). Elixir's typography no longer depends on whatever the machine
  happens to have installed — it renders identically everywhere, with
  the Segoe UI fallback still intact underneath.
- **Icons follow the theme.** The Lucide outline set gains `home`,
  `headphones`, and `audio-lines` glyphs, and icon tinting now reads the
  palette's dedicated `icon` token instead of a fixed grey.
- **Nothing moved.** Every dialog, the wizard, the tool grid, the
  settings rail — all exactly where they were, at exactly the same
  compact density. This milestone is the paint, not the floor plan. The
  dashboard redesign is M2.

## Also in this release (under the hood)

- **One palette to rule them all:** `ui_qt/theme.py` now carries the
  approved token set (light: bg `#F6F5F0`, surface `#FFFFFF`, accent
  `#3F634D`; dark: bg `#20231F`, surface `#292D28`, accent `#91AD91`)
  plus a purely additive `icon` token — all 21 pre-existing palette
  field names are pinned unchanged.
- **The de-hardcode sweep:** every theme-dependent colour literal that
  lived outside the theme system is gone (~35 hex + 16 rgba + ~20
  three-digit greys the census had missed). A central `rgba()` helper
  derives QSS/HTML translucent washes from palette hex, and a census
  test pins the outside-theme literal count at **zero**.
- **Typography split (user decision Q6):** the compact 11 px dialog
  scale is frozen — dialogs, wizard, and settings re-flow nothing —
  while the dashboard-facing scale (hero 28 / section 17 / tool 14 /
  sidebar 12 / body_lg 13) is added and M2-ready.
- **M2 primitives staged:** `SectionLabel`, `SidebarNavItem`, and
  `QuickToolCard` exist, follow the ToolCard house pattern, and are
  deliberately unwired (pinned unused by test until M2 wires them in).
- **The pins:** 22 hermetic source/AST pins — spec hex values, additive
  `icon` field, WCAG contrast floors (on-accent ≥ 6.5:1,
  primary-on-window ≥ 13:1, secondary-on-surface ≥ 4.7:1 in both
  modes), frozen dialog type scale, QSS rules, zero terracotta
  remnants, icon superset, zero-literal census, Inter bundling,
  primitives unwired — plus 5 Qt-behaviour pins that run on Windows and
  skip on the headless sandbox.
- **Suite state (sandbox, at this tree):** 8,374 passed / 28 failed /
  29 errors / 380 skipped / 7 xfailed — **zero NEW failures vs the M0
  baseline**. The failures are the five documented pre-existing ones
  (prompt-manifest drift ×1, eval-baseline drift ×2, VibeVoice timeout
  pins ×2) plus the sandbox's missing-libEGL environment artifacts.
  `ruff check`: only the 1 pre-existing `B023`.
