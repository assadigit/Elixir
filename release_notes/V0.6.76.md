reference at full resolution and establishing measurements. Every zone
of the reference was sampled programmatically (pixel scans for edges,
borders, glyph bands, and fills — the sample coordinates are recorded in
comments beside each palette value in `ui_qt/theme.py`):

## What changed (plain words)

- **Light theme gets the reference's exact warm grounds**, including four
  new palette tokens (`bg_sidebar`, `bg_header`, `bg_hero`,
  `bg_backdrop`) so the sidebar / header / hero / backdrop zones can
  each carry the subtly different warm tone the reference paints. Dark
  mode gets equivalent charcoal-green twins (geometry unchanged — dark
  mode is verified separately per the spec).
- **The dashboard type scale is re-measured**: the hero headline is
  41 px semibold (the reference renders a ~30 px ascender over two
  ~46 px lines), support copy 20 px, section headings 20 px, card
  titles 15 px, nav labels 13 px. The **dialog scale stays frozen**
  (dialogs must not re-flow).
- **Radii**: +10 px nav pill, +14 px cards, +16 px hero, +18 px shell.
- **New QSS surface rules** staged for the next structural commits: the
  floating `AppShell`, the `WindowBackdrop`, `QuickToolCard` and the
  dark `FeatureToolCard` (the reference's ninth card), the persistent
  `StatusStrip`, the `SidebarBrandCard`, the backend status pill, the
  frameless window controls (with the standard red close hover), the
  status-strip theme selector, and the "View all tools →" link.
- **Four Lucide glyphs added** (`minus`, `square`, `restore`,
  `arrow-right`) for the window controls and the hero CTA's arrow.
- The hero illustration compositing now flattens against `bg_hero`
  (stays in sync with the `QFrame#HeroCard` fill in both themes).
