# V0.6.84 — UI/UX correction Round 4: the logical-canvas recalibration — Manrope, the compact 3×3 Quick Tools grid, the complete sidebar (fixed Settings/About, no scrollbar, compact tagline), ONE theme control, and the softer hero

> **The correction spec behind this release:** the Round-4 audit
> (`ELIXIR_UI_UX_CORRECTION_ROUND_4.md`) measured the shipped V0.6.83.1
> dashboard (`now5.png`, a 1096×717 field window) against the approved
> reference (`508782d6-4b80-48be-9046-d081ce258b75.png`) and found the
> grid at two columns with clipped content, the sidebar scrollable, the
> tagline clipped, two theme controls, and generic typography. This pass
> fixes every one — and the root cause behind all of them.

## The root cause: raster-pixel calibration (the 1.536× inflation)

The V0.6.78–82 "ink-calibrated" rounds measured the reference PNG's
**raster pixels** (a 1536×1024 file) and wrote those numbers as
**logical-px** constants. The approved reference is a 1000×667 logical
canvas rendered at 1.536× — so every dashboard size those rounds shipped
was ~1.5× the reference's actual proportions:

| Element | V0.6.83.1 (raster-derived) | Reference (logical) | V0.6.84 |
|---|---|---|---|
| hero headline | 39 px | 26 px | **27 px base, bold** |
| hero support | 18 px | ~13.5 px | **14 px** |
| tool-card title | 17 px | ~12.7 px | **13 px** |
| tool-card description | 13 px | ~10.5 px | **10 px** |
| sidebar nav label | 14.5 px | ~12.5 px | **12 px** |
| "Quick Tools" head | 20 px | ~17 px | **17 px** |
| wordmark | 30 px | ~22 px | **22 px** |
| tool card height | 124 px | 80 px | **80 px** |
| nav row | 37 px | ~25 px | **27 px** |
| hero height (body 580) | 240 floor | 220 | **0.36 × body, clamp [192, 260]** |

That inflation is why the cards could never fit three columns at the
field window, why the nine nav rows overflowed the rail, and why the
tagline card clipped its own text — not the window, not the grid code:
the type was a size-and-a-half too big. The Round-4 calibration
re-measures every element against the reference's **logical** canvas
(cap-height and ink-width verified per glyph band) and lands the
structure at parity — measured at the matched 1000×667 shell:
hero 220/220, grid-top 315/319, row-3 top 495/495, card gap 10/10.

## §6 — the typeface: Manrope (selected by real comparison)

Both candidates were rendered in the actual application at the field
window, side by side (spec §6.3), and compared on the spec's criteria:

| Criterion | Manrope | IBM Plex Sans |
|---|---|---|
| hero headline | the exact two-line lockup | **wraps to a third line** |
| sidebar labels | every real tool name single-line | "Document → Markdown" wraps |
| card density | comfortable breathing room | wider letterforms crowd the arrow |
| character | modern geometric editorial — the reference's own character | more technical/enterprise |

**Manrope ships** (the spec's preferred first candidate, and the
comparison's winner): four static weights instantiated from the official
`Manrope[wght].ttf` variable font, bundled in `assets/fonts/` with the
SIL OFL 1.1 license, registered by `ui_qt.theme.load_bundle_font()` via
`app_paths.bundle_dir()` (source and frozen builds both resolve), with
the QSS stack falling back to Segoe UI Variable → Segoe UI → Helvetica
Neue → Arial if registration ever fails. The Inter TTFs are retired —
one primary family, consistently used.

## §2 — the Quick Tools grid: a true 3×3 at the acceptance sizes

- **Card minimum 80 px** (the spec's 80–90 band; the reference measures
  78–83), 11/9/11/11 padding, 24 px icon, 28 px arrow disc, 10 px gaps.
- The comfort/floor reflow tiers re-measured on the running Manrope
  stack: comfort 235, floor 230, chrome 90 — three columns hold at BOTH
  the 1096×717 field window (grid 865, need 725) and the 1000×667
  reference canvas (grid 744, need 725), with the page's own minimum
  under the viewport at both (511 ≤ 579 / 495 ≤ 529 — no scrollbar).
- Constrained desktops drop to 2 columns (~900 px windows) and 1 column
  below the floor — verified live; the featured card keeps its dark
  forest-green treatment and its reference-verbatim description on two
  lines at the field window.

## §3/§4 — the complete sidebar

- **No internal scrollbar at the reference size** — the compact stack
  (27 px rows, 34 px Home pill, tightened group spacings) fits the
  1096×717 rail with room to spare, live-verified
  (`verticalScrollBar().maximum() == 0`).
- **Settings/About move into a FIXED lower region** outside the scroll
  area (spec §3.3) — never scrolled away, never pushing the tools out
  of view.
- **Single-line labels**: the 12 px Manrope labels fit every real tool
  name on one line down to a 188 px rail (the field window's 197 px rail
  included); only the narrowest rails (the 180 px formula floor) wrap —
  intentionally, with rows that grow to accommodate.
- **The tagline card compacts** (12 px top inset, 46 px art strip,
  ~100 px total) and the full "Knowledge, distilled into clarity." is
  visible at every size.

## §5 — ONE theme control

The top-bar moon toggle is removed; the bottom status strip's
"Light Theme ▾" selector (with its Light/Dark menu, keyboard-operable)
is the single visible theme control. The underlying engine, persistence,
and the `_toggle_theme` path are untouched — only the duplicate visible
control is gone, and the top bar's spacing redistributes naturally.

## §7/§8 — the hero

- The still-life remains a **true transparent RGBA composite** (the
  V0.6.83 fix) — verified again over both themes.
- **The background washes recede**: the sage circles drop to 22/17/13
  alpha and shift right, so the books and quill are the focal point
  ("Refine the background shapes if they compete with the artwork").
- The headline becomes a **bold display weight** (the reference's ink is
  visibly heavier than semibold), and the CTA's painted arrow gets a
  reserved right inset (asymmetric padding, floor 40 px) so the label
  can never collide with it at constrained scales — the 900-px review
  caught "Conversio→n" before the fix.

## Remaining, honestly

- The reference mockup's typeface is synthesized and ~8–30 % narrower
  than any real font at equal size; Manrope at the logical sizes is the
  closest real-world match, and the structure (not the glyph shapes) is
  at parity.
- On the narrowest rails (the 180 px formula floor — windows ≲ 1000 px)
  the two longest tool labels wrap to two lines by design.
- The dark theme's card descriptions use the app-wide muted token — the
  same contrast as V0.6.83.1, flagged "minor" by the review, unchanged
  deliberately (a palette-wide change is out of Round-4 scope).
