## What this is

The UI/UX redesign's second milestone: the dashboard itself. M1 (the
`V0.6.70-M1` pre-release) rebuilt the visual language — colours, fonts,
icons, tokens. V0.6.70 now rebuilds the *layout* on top of it: the app
you open is a dashboard, not a tabbed utility.

## What you get (in plain words)

- **A fixed sidebar replaces the tab bar.** A compact rail on the left —
  Home, then Processing, Utilities, and Audio groups, with Settings and
  About pinned at the bottom — is always visible, with icons and labels.
  Nothing collapses, nothing hides.
- **The home page leads with one clear action.** A short purpose line,
  then the Full Conversion hero: "Turn documents into clear, structured
  knowledge." with a single **Start Conversion** button. It opens exactly
  the same guided wizard as before — the wizard's 10 steps are untouched.
  The books-and-quill illustration sits beside it at reduced size and
  quietly disappears when the window gets too narrow for it.
- **Quick Tools replace the old 4×3 wall of cards.** Every secondary tool
  is still there — under the hero, grouped Processing / Utilities /
  Audio, with the same names, the same one-line descriptions, and the
  same click behavior (each opens its own dialog, as before). The grid
  reflows 4 / 3 / 2 columns wide as you resize the window.
- **The power tools moved, they didn't vanish.** Queue, Output Scanner,
  Bullet Audit, and Hallucination Audit left the main navigation (it was
  crowded) and now live behind **About & System → "Experimental tools"**.
  Everything still works: dropping a PDF anywhere still queues it (and
  now takes you to the Queue page so you can see it land), and Packets
  output still opens the Hallucination Audit.
- **A quieter header.** The big "✨ Process Wizard" button is gone — the
  hero owns that job now. The three LLM status lights collapsed into one
  small dot (hover it for the summary; the full per-client lights —
  Ollama, llama.cpp, LM Studio — now live in About & System, live-updating).
  The compact **Merge** link stays (it's a real action, not navigation).
- **Both themes, everywhere.** The sidebar, hero, cards, and the new
  About & System sections all follow the light/dark toggle, including the
  hero illustration, which is re-composited for the active surface colour.

## The decisions baked in (user-approved, Q1–Q8)

Audio group in the sidebar (Q1) · experimental four behind About & System
(Q2) · one aggregate header dot (Q3) · Inter bundled since M1 (Q4) · the
supplied hero illustration at reduced size (Q5) · compact dialogs +
larger dashboard type (Q6) · the header wizard button removed once the
hero existed (Q7) · one bump per milestone: this is V0.6.70 (Q8).

Two M2 judgement calls, made and documented per the handoff prompt:
**Merge stays in the header** (a real cross-output action; the grid stays
exactly the tool list), and **the old tab-flash highlight was dropped**
(a page switch now changes the whole content area — no tiny label needs
to blink for you to notice).
