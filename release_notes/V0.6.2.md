# V0.6.2 — the two user-reported bugs fixed: the negative elapsed timer (midnight-crossing) · the thin-chapter over-generation

Both bugs came from a real ~2h40m book run on the operator's rig. Both root-caused live before the fixes; 19 of the 34 new tests fail on the pre-fix HEAD (git-stash-verified).

## Fix 1 — the elapsed timer that went negative

"Elapsed: -21:34:45" after a conversion that crossed midnight. Root cause: `QTime.currentTime() + secsTo` — QTime is a time-of-DAY type with no day tracking; `QTime(23:34:45).secsTo(QTime(02:00:00))` is **-77685** (verified empirically), which the floor-division formatter rendered as a negative `-HH:MM:SS`. A >24h run wrapped modulo 24h. **Fix:** `time.monotonic()` (negative-impossible, wrap-impossible), clamped at zero as belt-and-braces. Pinned by the midnight-crossing drive, the never-negative sweep, the 25-hour run, the clock-skew clamp, and the restart.

## Fix 2 — thin chapters that generated MORE than the source

A book with 1-2 page chapters shipped exec + bullets + thorough ABOVE the source word count, padded with rephrased near-duplicate bullets. FOUR stacked defects, all in the thin regime (W < 800):

- **the thorough 120-word floor broke the 45% cap** — a 150-word chapter was told to write 120 words thorough (80% of source); a 100-word chapter, 100 words (100%). The fraction is now the true cap.
- **the exec 60-word floor broke the 20% cap** the same way. Fixed identically.
- **the bullet additive budget was unbounded for thin chapters** — `bullet_cap()=0` ("no cap") let the Tier-2/scholar gap-fill keep inserting with NO room limit → "repetitive bullets rephrasing the same concepts". Thin chapters now get the source-scaled bullet budget back; normal chapters (≥800w) keep 0 (the V0.4.23 directive stands).
- **no COMBINED budget existed** — the three section targets structurally sum to ~115% of a thin chapter. The thin `length_budget_block` now states a combined aim (~75%), a bounded bullet range ("N-M", not "at least N — NO MAXIMUM"), and one-distinct-idea-per-bullet; `expansion_audit` measures the combined ratio (thin-scoped) and F1 logs it.
- **Tier-2 insertions bypassed the near-duplicate check** (only EXACT string equality was checked) — rephrased bullets appended unconditionally. New guard: `DedupService.is_near_duplicate` (token_set_ratio ≥ 75, fail-open).
