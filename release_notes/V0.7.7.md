## The one finding (fixed in this release)

**HY-1 — legacy settings files kept their dead OCR keys forever.**
Every settings.json created before V0.7.0 still carries the two OCR keys
purged during the rework (the log-only scan-detection flag and the
full-OCR alias), which trips two "Unknown setting" warnings in the log
on every app start — forever. The V0.7.4 dead-key pattern (pop them from
legacy files on load) had not been applied to these two. Reproduced live
on the audit rig's own legacy file; the migration now pops both keys so
old files self-clean on the first launch (living OCR settings are
untouched; the keys have had no readers since V0.7.0/V0.7.1 — re-pinned
by 4 new tests in `tests/test_v0760_audit.py`).
