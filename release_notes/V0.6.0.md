# V0.6.0 — the dedicated-tools verification campaign: every tool card verified end-to-end · 30 defects fixed · 730 new tests

The first campaign-style release: every one of the 12 dashboard tool cards, the 3 internal tabs, and the full output-rider family was traced from the card → routing → dialog → service and verified end-to-end with real fixtures (real PDFs, DOCX, EPUBs, real ffmpeg audio, real Qt worker threads) — not source-pin smoke.

## What was verified (and fixed where it broke)

- **Cutter, Image Extractor, OCR, Doc→MD** — 32/41/57/48 tests. 14 defects: silent whole-document cuts on unparseable ranges, "✅ 0 images" success on unopenable files, broken tesseract path on non-Windows, garbage page ranges OCR-ing the whole document, and more.
- **Summarization, Translation, Styler + Packets** — 37/143/68 tests, LIVE through the LLM shim. 12 defects including the mid-translation error written to the output file and reported as ✅ success.
- **TTS, Podcast (script + audio), Transcribe** — 107/68 tests. 9 defects: known-bad default model tags, the year-mangling "2020-two" regex, the phantom "# Source Material" bullet.
- **Output riders** — 53 tests across all 16 output formats: anki, epub, obsidian, study guide, mind map, quote bank, citation graph, evidence map, social, briefing, flashcards, QA, reference, chapters. 2 epub fixes (XML escaping, DEFLATE mimetype).
- **Internal tabs** — Output Scanner, Batch Queue, Hallucination Audit: 76 tests, 3 defects (drifted regenerable-key sets, copy button copying truncated display text, contradictory verdict reasons).

## The numbers

- **730 new tests** across 11 test files; **40 defects found and fixed** — every fix content-agnostic (Rule 1: no book vocabulary in runtime code).
- Full suite: **14 failed / 6,474 → 7,188 passed** — the 14 are the pinned environment families (VRAM policy + segmentation + v182032), unchanged from the session baseline. Net-green throughout.
- ruff check + format clean on every touched file.

## Test path

Unzip the release, `pytest tests/test_v0600_tool_*_e2e.py -q` — the 3-layer house pattern (pure helpers → service on real fixtures → dialog drives through the real QThread with modals stubbed to recorders).
