# V0.6.77 — visual-fidelity pass 2/N: the reference's floating shell, sidebar IA, top-bar chrome, and status strip land · frameless rounded window with working min/max/close · 265 px rail with the brand row + nine tools · the pill/Settings/divider/moon/controls bar · the Ready / Light-Theme strip

> The structure commit of the **visual-fidelity correction pass**
> (`ELIXIR_VISUAL_FIDELITY_CORRECTION_SPEC.md`): the app's silhouette now
> matches the approved reference's composition. The hero and the Quick
> Tools grid follow in the next versions.

## The window is now the reference's floating surface

- **Frameless + rounded**: the native frame is gone; a `QFrame#AppShell`
  with 18 px corners sits on a ~21 px `WindowBackdrop` margin with a
  palette-derived drop shadow (dark at the bottom edge, subtle up top —
  measured against the reference's own shadow density).
- **The controls are real, not decoration**: minimize, maximize/restore
  (icon swaps), and close (red hover) live at the top bar's right end at
  the reference's ~54 px pitch. Drag the top bar to move the window;
  grab any edge/corner to resize via the platform's own
  `startSystemResize` (Snap layouts and DPI stay native); double-click
  the bar to maximize/restore.
- **Maximized behaves correctly**: margins → 0, corners square, shadow
  off (QSS `[maximized=true]` variants) — the standard frameless
  convention.

## The sidebar (265 px — exactly the reference's 17.3%)

The brand row (leaf emblem + "Elixir" wordmark) moved **into the rail**;
Home carries the reference's pale-sage pill; one **TOOLS** group holds
the nine core tools in the reference's order (Full Conversion, then
Summarization, Document → Markdown, Translation, Markdown Styler,
Packets of Knowledge, OCR Service, PDF/DOCX Cutter, Image Extractor);
a divider; Settings and About; the tagline card stays anchored at the
bottom (leaf + "Knowledge, distilled into clarity." over the muted
landscape).

**The Audio group left the primary navigation** — the reference rail
carries only the nine core tools. Nothing was deleted: TTS, Podcast
Maker, and Transcribe remain on the full tools page ("View all tools →"
lands there) **and** in About & System's new **"More tools & actions"**
section, alongside the Merge Books action that retired from the header
(the merge flow itself is byte-for-byte unchanged).

## The top bar (68 px, over the content only)

Right-clustered exactly as the reference draws it: the **backend status
pill** (a sage dot when the configured backend answered the last probe +
its name + a chevron; click opens Settings; tooltip lists every client),
the labelled **Settings** action, a subtle divider, the theme toggle,
then the window controls. The old brand + subtitle, Merge link, LLM
lights, and About button are all retired from the bar — the per-client
lights live on in About & System, fed by the same poll loop.

## The bottom status strip (56 px, full inner width)

A sage dot + **"Ready"** on the left — a real status surface wired to
the wizard's conversion lifecycle ("Converting…" while a run is in
flight, back to Ready after). On the right: a divider, the sun/moon
glyph, "Light Theme" + a chevron opening a working **Light / Dark**
menu.
