# Chapter Heading Keywords

> This file is **editable**. Add or remove keywords (one per line) to help
> the segmenter detect chapter boundaries — especially in scanned PDFs
> where there is no digital table of contents.
>
> **Format:** One keyword per line. Lines starting with `#` are comments
> and are ignored. Blank lines are ignored. Keywords are case-insensitive.
>
> **How it works:** When the segmentation strategy is set to "heading" (or
> "auto" which may fall back to heading), the segmenter looks for lines
> that *start with* one of these keywords followed by a number, colon, or
> space — e.g. "Chapter 1", "فصل دوم", "Part III:", "Lesson 5 —".
>
> **Editing:** Change this file in any text editor, then reload settings.
> You can also edit it directly from Settings → Output → Segmentation.
